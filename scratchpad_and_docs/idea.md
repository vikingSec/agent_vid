# IDEA - An in-browser video editor that can be used by agents to edit videos

I want to be able to hand a video to an agent and let the agent edit it. I want a lot of power for this project, everything from editing the way the video looks, adding LUTs, trimming video, adding audio, creating animated text and more. We can start small, though.

The project will be open source and will use Claude Code to interact with it primarily.

I want the video to be human editable too. I also want there to be a "diff" type interface that you can use to roll back changes, see changes that have been made, etc.
